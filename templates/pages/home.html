What's inside

Session authentication

Argon2id hashes, session id rotation on sign-in, CSRF tokens on every form and a signed-out state you can actually see.

SeaORM + migrations

The database is created on first boot when it is missing, then migrations run automatically. Entities mirror the schema one file at a time.

Askama + Alpine.js

Templates are compiled and type checked with your Rust code. Alpine handles theme switching, password visibility and form state without a build step.

Quick start

shell 
cp .env.example .env
cargo run

Point DATABASE_URL at your Postgres instance. The app creates the database when it does not exist yet and applies pending migrations on boot.
